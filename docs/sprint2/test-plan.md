## 1. Продукт і межі тестування

«СтейНау» — система онлайн-бронювання номерів готелю.

У межах тестування розглядаються:

- гостьова частина вебзастосунку;
- адмінпанель;
- функції бронювання;
- перевірка доступності номерів;
- контактна форма;
- модуль бізнес-логіки;
- сезонні тарифи;
- політика скасування;
- розрахунок вартості проживання;
- валідація даних бронювання.

Поза межами тестування:

- онлайн-оплата;
- мобільні застосунки.

Гостьова частина й адмінпанель працюють як вебзастосунок.
Підтримувані браузери згідно з SRS — поточні версії Chrome і Firefox.

Модуль бізнес-логіки реалізований на Java 17 та містить класи
`BookingValidator`, `PriceCalculator` і `Availability`.
