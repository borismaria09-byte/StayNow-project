## Питання для Demo

1.  **Щодо підтримуваного середовища та формату дат.**
Чи підтверджуєте ви, що гостьова частина й адмінпанель мають підтримувати дві останні стабільні основні версії Google Chrome і Mozilla Firefox? Також чи підтверджуєте ви запропонований формат дат у полях Check In / Check Out — дд/мм/рррр незалежно від налаштувань браузера або операційної системи?

2. **Щодо функціональних правил бронювання.**  
Чи підтверджуєте ви такі запропоновані командою правила: Service fee = £15; перелік доступних номерів формується не довше ніж за 2 с; для звітів за майбутні періоди використовуються підтверджені бронювання?

3. **Щодо повідомлень і підтвердження бронювання.**  
Які саме дані повинні міститися в email-підтвердженні після створення бронювання? Також чи достатньо для обробки повідомлення адміністратором дій «відкрити повідомлення для перегляду» та «позначити його прочитаним»?

4. **Щодо нефункціональних критеріїв.**  
Чи підтверджуєте ви запропоновані командою числові критерії: завантаження сторінки до 3000 мс у мережі 2G, навантаження 500 RPS із 95-м перцентилем часу відповіді не більше 200 мс, а також проходження сценарію бронювання 90 % користувачів без підказок менш ніж за 3 хвилини? Які критерії приймання слід використовувати для результатів сканування OWASP Top 10?

5. **Щодо єдиного оформлення форм гостьової частини.**  
Чи підтверджуєте ви запропоноване командою рішення додати вимогу GUI-95, згідно з якою текстові поля форм гостьової частини мають підпис або placeholder, основна кнопка дії розташовується після полів форми, а повідомлення про помилки оформлюються відповідно до GUI-60?
