# BPMN-моделі бізнес-процесів системи «СтейНау» (Sprint 1)

У цій папці розміщено фінальні BPMN 2.0 діаграми для 4 основних бізнес-процесів продукту «СтейНау»:
1. **Process 1:** Бронювання номера (`process_1_booking`)
2. **Process 2:** Заселення і виселення (`process_2_checkin_checkout`)
3. **Process 3:** Скасування і повернення коштів (`process_3_cancellation`)
4. **Process 4:** Обробка повідомлень гостей (`process_4_guest_messages`)

## Інструменти та версії
* **Інструмент моделювання:** [draw.io](https://app.diagrams.net/) (Web-версія / Desktop v24.x)
* **Версія стандарту:** BPMN 2.0

## Формати файлів
* `.drawio` — вихідні редаговані файли діаграм.
* `.png` — експортовані графічні зображення для перегляду та звітності.

## Як відкрити вихідні файли (.drawio)
1. Перейдіть на веб-сайт [app.diagrams.net](https://app.diagrams.net/).
2. Натисніть **Open Existing Diagram** (Відкрити існуючу діаграму).
3. Оберіть відповідний файл `.drawio` з папки `docs/sprint1/bpmn/`.
