## 3. Команди відтворення

Команди з README у звичайному терміналі з налаштованим `PATH`:

```bash
mvn -v
mvn clean test
mvn test -DexcludedGroups=none
```

Фактично використані еквівалентні команди в PowerShell:

```powershell
cd D:\lab5Tzyaps\StayNow-project
git status --short
git pull origin main
git rev-parse HEAD
& $mvn clean test
& $mvn test "-DexcludedGroups=none"
```

Для окремої перевірки власних UI-тестів:

```powershell
& $mvn "-Dtest=MykhailenkoUiTest" "-DexcludedGroups=none" test
```

### 4.3. Повторна перевірка UI-07/UI-08 після локального виправлення

Під час діагностики UI-08 встановлено відсутність елемента `id=submitContact` на сторінці; присутня кнопка `Submit`. При звичайному кліку по актуальному локатору відтворювався `ElementClickInterceptedException`. Для стабілізації автоматизованого сценарію виконано прокрутку й JavaScript-клік по знайденій кнопці. Діагностичні `System.out.println` згодом видалено.

Останній незалежний запуск власного класу від **18.11.2026 19:09**:

```text

BUILD SUCCESS
```

UI-07 та UI-08 пройшли. Обмеження: JavaScript-клік не перевіряє можливість звичайної взаємодії користувача з кнопкою. **Після цього виправлення новий повний прогін усієї збірки ще не зафіксований.**
