## 3. Команди відтворення

Команди з README у звичайному терміналі з налаштованим `PATH`:

```bash
mvn -v
mvn clean test
mvn test -DexcludedGroups=none
```

Фактично використані еквівалентні команди в PowerShell:

```powershell
cd D:\lab5Tzyaps\StayNow-project
git status --short
git pull origin main
git rev-parse HEAD
& $mvn clean test
& $mvn test "-DexcludedGroups=none"
```

Для окремої перевірки власних UI-тестів:

```powershell
& $mvn "-Dtest=MykhailenkoUiTest" "-DexcludedGroups=none" test
```

Діагностичні `System.out.println` згодом видалено.

