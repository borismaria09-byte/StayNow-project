## 3. Команди відтворення

Команди з README у звичайному терміналі з налаштованим `PATH`:

```bash
mvn -v
mvn clean test
mvn test -DexcludedGroups=none
```

Фактично використані еквівалентні команди в PowerShell:

```powershell
cd D:\lab5Tzyaps\StayNow-project
git status --short
git pull origin main
git rev-parse HEAD
& $mvn clean test
& $mvn test "-DexcludedGroups=none"
```

Для окремої перевірки власних UI-тестів:

```powershell
& $mvn "-Dtest=MykhailenkoUiTest" "-DexcludedGroups=none" test
```

Обидва результати отримано на Windows 11 в окремій локальній копії проєкту. У складі повного набору виконано 59 unit-випадків і 8 UI-випадків. `BUILD FAILURE` є очікуваним наслідком цих одинадцяти невдалих перевірок; **нових UI `Failures` або `Errors` у повному прогоні немає**.

**Точність версій:** для окремого запуску `mvn clean test` раніше було підтверджено SHA `39c11b5db1a892c944753b263130c09b86fd17f9`. У наданому виводі останнього повного прогону о 22:30 **немає результату `git rev-parse HEAD`**, тому точний SHA цього локального запуску не підтверджено. Стан гілки `main` після виправлень UI-03 у GitHub: `08cc037bbe279d3288ee966590f9b93a12dda440`; це **не слід ототожнювати** з непідтвердженим SHA локального прогону.
