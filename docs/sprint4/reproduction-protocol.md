## 3. Команди запуску

Перевірка версії Maven:

```bash
mvn -v
```

Запуск тестів відповідно до README:

```bash
mvn clean test
```

Запуск усіх тестових груп, включно з UI:

```bash
mvn test -DexcludedGroups=none
```

Окремо перевірено UI-тести виконавця:

```bash
mvn -Dtest=MykhailenkoUiTest -DexcludedGroups=none test
```

## 7. Звірка Maven Surefire

Перевірено `docs/sprint4/surefire-summary.md`.

На момент аудиту командний документ містив результати попереднього запуску: 8 тестів без помилок. Ці показники не відображають повний набір Sprint 4, який під час незалежної перевірки містив невдалі модульні тести.

Необхідно оновити підсумок Surefire за актуальними результатами повного запуску. Відповідальний — керівник тестування.

## 8. Виявлені зауваження

1. У модулі бізнес-логіки виявлено дефекти перевірки дат та округлення вартості.
2. Початковий повний запуск містив помилки UI-тестів, причини яких потребували додаткової перевірки.
3. Підсумок Surefire необхідно синхронізувати з актуальним станом тестів.
4. Для коректного аудиту потрібно розрізняти дефекти продукту, помилки тестових сценаріїв та проблеми середовища.
5. Результати окремого успішного запуску UI-07/UI-08 не означають успішного виконання всього тестового набору.

## 9. Висновок аудитора

Незалежна перевірка підтвердила можливість запуску автоматизованих тестів StayNow за допомогою Maven.

Водночас повний набір тестів виявив порушення бізнес-правил, тому загальний результат початкової перевірки — BUILD FAILURE.

Власні UI-тести UI-07 та UI-08 після виправлення тестового сценарію виконуються успішно.

Дефекти BL-10 та BL-50 зареєстровано в GitHub Issues #12 і #13. Для завершення командної перевірки необхідно актуалізувати підсумковий звіт Surefire та повторити повний запуск після узгодження змін.
