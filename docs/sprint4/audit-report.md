### 3.3. Уточнення та повторна перевірка власного UI-08

Діагностика сторінки `https://automationintesting.online/` виявила, що елемент з `id=submitContact` відсутній (`found: 0`), але видима кнопка з текстом `Submit` існує. Після зміни локатора на `//button[normalize-space()='Submit']` звичайний Selenium `.click()` завершився `ElementClickInterceptedException`. Після прокрутки й виконання JavaScript-кліку сценарій пройшов, включно з перевірками імені, теми та зникнення кнопки форми.

Останній окремий прогін **18.11.2026 о 19:09 (Europe/Kyiv)** після видалення діагностичних повідомлень:

```text
-Dtest=MykhailenkoUiTest -DexcludedGroups=none test
Tests run: 2, Failures: 0, Errors: 0, Skipped: 0
BUILD SUCCESS
```

**Обмеження:** JavaScript-клік обходить перевірку перекриття елемента, тому цей результат підтверджує виконання автосценарію, але не підтверджує, що кнопку можна натиснути звичайним користувацьким кліком. На той момент, 18.11.2026, після виправлення власного класу повний набір із 62 виконань повторно не запускався; фінальний повторний прогін виконано 20.11.2026 і наведено в §3.4.
