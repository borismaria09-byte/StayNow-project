## 6. Зауваження для демонстрації

1. **Одинадцять `Failures` не є збоями тестового середовища**: тести правильно сигналізують про шість відомих дефектів бізнес-логіки v1 (#12, #13, #19, #25, #26, #28).
2. **Усі вісім UI-тестів завершилися без помилок** в останньому повному Windows-прогоні (20.11.2026, 22:30).
3. **Для повної відтворюваності** при демонстрації слід виконати `git rev-parse HEAD` безпосередньо перед запуском і зберегти лог Maven: точний SHA останнього переданого повного запуску у виводі відсутній.
4. **UI-08** використовує JavaScript-клік; цей підхід не перевіряє можливість натискання кнопки звичайним WebDriver-кліком.
